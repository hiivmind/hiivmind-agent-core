# Inspection of step 1a

The third review (finding C13) found obligations that no run-time check shows: packaging, dependency boundaries, the
content of the engine documents, the fixed vocabulary, framework isolation. This document answers each by looking at
the code. Every answer names the file and line that shows it. Lines are those of the commit that adds this file.

The requirement IDs are those of the two specifications linked in the [README](../README.md#specifications).
